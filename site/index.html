Download

Pick your platform. Every build contains the whole scene. What else it can do depends on the platform: see what works where.

Linux

Every feature: the Hyprland panel, the Windows VM, and apps opening right in the scene. Best on Omarchy.

AppImage any distro · x64 .deb Debian, Ubuntu · x64
Install
  1. AppImage: chmod +x Spatial-Desktop-linux-x86_64.AppImage, then run it.
  2. Debian/Ubuntu: sudo apt install ./Spatial-Desktop-linux-amd64.deb
  3. For the Hyprland panel: sudo pacman -S wayvnc (or your distro's package).

Windows

The scene, window panels from any window or screen, layouts, launcher and music.

Installer Windows 10/11 · x64
Install
  1. Run the installer.
  2. It isn't code-signed yet, so SmartScreen may warn you: choose More info → Run anyway.

macOS

The scene and window panels (allow Screen Recording when asked). Apple silicon and Intel in one download.

Disk image macOS 12+ · universal
Install
  1. Open the .dmg and drag Spatial Desktop to Applications.
  2. It isn't notarized yet, so the first time, right-click → Open → Open. If macOS still refuses, run xattr -dr com.apple.quarantine "/Applications/Spatial Desktop.app".

Android & Quest

The scene as an app, offline, on phones, tablets and Meta Quest (as a 2D window). For VR on Quest, use the web version in the Quest Browser.

APK Android 7+ · Quest
Install
  1. Phone or tablet: open the APK and allow installing from your browser when asked.
  2. Quest: enable developer mode, then install with adb install Spatial-Desktop-android.apk or SideQuest. It appears under Unknown sources.

Web & VR headsets

Nothing to install. Runs in any modern browser, with real VR in the Quest Browser and other WebXR browsers. Add it to your home screen from the browser menu.
