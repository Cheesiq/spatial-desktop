Linux

Every feature: the Hyprland panel, the Windows VM, and apps opening right in the scene. Best on Omarchy.

AppImageAny distro · x64 .deb packageDebian, Ubuntu · x64
Install steps
  1. AppImage: make it executable, then run it.
    chmod +x Spatial-Desktop-linux-x86_64.AppImage
  2. Debian/Ubuntu:
    sudo apt install ./Spatial-Desktop-linux-amd64.deb
  3. For the Hyprland panel (or your distro's package):
    sudo pacman -S wayvnc

Windows

The scene, window panels from any window or screen, layouts, launcher and music.

InstallerWindows 10/11 · x64
Install steps
  1. Run the installer.
  2. It isn't code-signed yet, so SmartScreen may warn you: choose More info → Run anyway.

macOS

The scene and window panels (allow Screen Recording when asked). Apple silicon and Intel in one download.

Disk imagemacOS 12+ · universal
Install steps
  1. Open the .dmg and drag Spatial Desktop to Applications.
  2. It isn't notarized yet, so the first time, right-click → Open → Open. If macOS still refuses, run:
    xattr -dr com.apple.quarantine "/Applications/Spatial Desktop.app"

Android & Quest

The scene as an app, offline, on phones, tablets and Meta Quest (as a 2D window). For VR on Quest, use the web version in the Quest Browser.

APKAndroid 7+ · Quest
Install steps
  1. Phone or tablet: open the APK and allow installing from your browser when asked.
  2. Quest: enable developer mode, then install with SideQuest or:
    adb install Spatial-Desktop-android.apk
    It appears under Unknown sources.

Web & VR headsets

Nothing to install. Runs in any modern browser, with real VR in the Quest Browser and other WebXR browsers. Add it to your home screen from the browser menu.
